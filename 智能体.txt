二、 如何填入您的 DeepSeek API Key（仅需一行配置）
--------------------------------------------------------------------------------
方式 1（配置在 Python FastAPI 目录）：
在 `/home/liming/partjava/i/partjava-ai/.env`（或项目根目录 `/home/liming/partjava/i/.env.local`）中写入：
```env
DEEPSEEK_API_KEY=sk-您的真实DeepSeek密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
DEEPSEEK_MODEL_FLASH=deepseek-flash
DEEPSEEK_MODEL_PRO=deepseek-v4-pro
```
（注：`.env` 与 `.env.local` 均已在 `.gitignore` 中设为忽略，绝不会上传泄露到 GitHub！）

方式 2（启动 Python FastAPI 微服务）：
```bash
cd /home/liming/partjava/i/partjava-ai
pip install -r requirements.txt
python3 main.py
```
（即使不手动启动 `python3 main.py`，前端 `/api/ai/agent/stream` 也会自动读取 `.env.local` 中的 `DEEPSEEK_API_KEY` 直接工作！）
