二、 DeepSeek-V4 双模型与官方搜索工具接口规范（2026-10-17 最新版）
--------------------------------------------------------------------------------
1. 模型矩阵（使用同一个 DeepSeek API Key 鉴权）:
   - 主力高速模型: `deepseek-flash`
     * 指向: DeepSeek-V4.1-Flash-1017
     * 特性: 支持思考模式与非思考模式，具备视觉理解能力（Vision），上下文窗口高达 1M。
     * 用途: 负责日常极速流式对话、全站 310+ 页面导航匹配、当前页面长文伴读解析、自动总结生成结构化 Markdown 笔记。
   - 深度推理与搜索模型: `deepseek-v4-pro`
     * 指向: DeepSeek-V4-Pro-0813
     * 特性: 推理与工具调用能力更强（不支持 Vision），原生支持内置 `web_search` 工具。
     * 用途: 负责「智能体四」的联网深度搜索、专业技术文档查证、疑难架构与算法深度解答。

2. DeepSeek 官方自研搜索引擎与网页抓取 API（2026年10月17日开放）:
   - 鉴权方式: `Authorization: Bearer <DEEPSEEK_API_KEY>`
   - 独立工具端点:
     (1) 网页搜索接口: `POST https://api.deepseek.com/v1/tools/search`
         用途: 根据关键词执行全网搜索，返回高相关度网页标题、URL、摘要列表。
     (2) 网页抓取接口: `POST https://api.deepseek.com/v1/tools/fetch`
         用途: 传入搜索得到的权威 URL，抓取并解析网页正文内容供大模型阅读总结。
   - 模型内置搜索工具:
     在调用 `deepseek-v4-pro` 的 `/v1/chat/completions` 接口时，可通过 `tools: [{"type": "web_search"}]` 让模型自动触发服务端联网搜索与抓取。
   - 计费说明: Search / Fetch 独立接口为 5元/千次（仅成功返回结果计费），服务端自动调用在 2026-11-01 前免费。前端提供显式 `[🌐 联网深搜 (Pro)]` 开关，按需开启，精准可控。

三、 Python FastAPI 四大专职智能体（Multi-Agent）详细架构设计

在项目根目录新建微服务文件夹 `/home/liming/partjava/i/partjava-ai/`（运行端口 8000），由 1 个总控路由（Supervisor Router）调度以下 4 个专职智能体：

【智能体一：站内领航与页面伴读智能体 (Site Navigator & Page-Reader Agent)】
--------------------------------------------------------------------------------
- 驱动模型: `deepseek-flash`（利用 1M 超大上下文窗口）
- 输入上下文:
  1. 全站 310+ 课程与功能路由索引表（自动解析自 `app/_shared/data/navigation.ts`）：
     * 计算机（13门学科：C++、Python、Java、SQL、数据结构与算法、操作系统、Linux、计算机网络、Web前端、Go、PHP、物联网、计算机组成原理）
     * 人工智能（9门学科：机器学习、深度学习、强化学习、NLP、计算机视觉、推荐系统、智能机器人、AI程序设计、数据挖掘）
     * 网络安全（9门学科：网络基础、安全防护、渗透测试、密码学、前端安全、逆向工程、安全开发、安全运维、区块链安全）
     * 软件工程（10门学科：架构与设计模式、开发规范与测试、Java EE、安卓、.NET、云计算、大数据、智能搜索引擎、软件建模、动画与游戏）
     * 核心功能区：`/challenges`（星际编程闯关）、`/code/editor`（在线代码沙箱）、`/notes`（随堂笔记）、`/tools/game`（解压小游戏）、31 个 3D 算法可视化器。
  2. 用户当前正在浏览的页面上下文（复用 `app/_shared/components/ai/useAiChat.ts` 中的 `collectPageContent()`）：
     * 自动提取当前网页的 `window.location.pathname`、`main h1/h2` 标题、当前激活的小节 Tab 以及页面正文前 6000 字。
- 核心功能:
  1. 伴读答疑：用户打开 3D 黑猫问“这页讲的重点是什么？”或“帮我解释这页的第2段代码”，智能体直接结合当前页面正文精准作答。
  2. 站内指路：用户问“你们网站有讲红黑树 / Spring Cloud / SQL注入 的页面吗？”，智能体自动返回对应解答，并输出结构化站内路由卡片 `site_links: [{ title, href, category }]`，在黑猫气泡底部渲染成可点击的跳转胶囊按钮！

【智能体二：知识提炼与自动写笔记智能体 (Note Summarizer & Writer Agent)】
--------------------------------------------------------------------------------
- 驱动模型: `deepseek-flash`（JSON 结构化输出）
- 触发方式:
  1. 点击底部输入坞的 `[📝 总结写笔记]` 快捷按钮；
  2. 在聊天框输入自然语言指令（如：“袋子，帮我把刚才聊的内容写成笔记”、“把当前页面的核心考点总结成一篇笔记”）。
- 核心功能与数据流:
  1. 智能体综合「当前多轮对话记录」+「当前学习页面正文」+「刚才联网搜到的资料」，提炼生成严格匹配后端 `partjava-backend` 数据库实体 `Note.java` 的 JSON 对象：
     ```json
     {
       "title": "精准简短标题（30字以内）",
       "content": "## 核心概念\n...\n## 关键代码示例\n```java\n...\n```\n## 常见面试坑点\n...",
       "category": "后端",
       "technology": "Java",
       "subcategory": "多线程与并发",
       "tags": ["Java", "并发编程", "虚拟线程"],
       "isPublic": false
     }
     ```
  2. 前端黑猫收到 `note_draft` 事件后，触发 `^ ^` 开心跳跃，并在嘴巴放射出的气泡里展示「📝 笔记生成完毕卡片」，提供两个按钮：
     * `[⚡ 一键存入我的笔记]`：直接调用 `POST /api/notes`（由 `NoteController.java` 写入 MySQL `notes` 表），成功后显示 `[👀 查看已保存笔记 (/notes/{id})]`。
     * `[✏️ 预览与编辑后保存]`：直接唤起项目中已有的可拖拽弹窗组件 `app/_shared/components/ai/NotePreviewModal.tsx`，允许修改分类/标签/内容后再保存。

【智能体三：编程解题与 3D 灵动伴侣智能体 (Code Tutor & 3D Companion Agent)】
--------------------------------------------------------------------------------
- 驱动模型: `deepseek-flash`
- 核心职责:
  1. 赋予 3D 黑猫“袋子”鲜活傲娇又专业的助教人设，负责日常算法讲解、代码 Debug、面试八股文抽查与学习计划制定。
  2. 实时输出「3D 情绪与姿态指令协议（Emotion & Posture Protocol）」：
     * 在每次流式回复的首包推送动作信令，直接控制 `catShaderAndRig.ts` 中的 `RiggedCatController`：
       - `mood: "happy"`   -> 触发 `triggerHappyJump()`，像素眼变成 `^ ^` 弯月笑眼、竖耳原地轻跳、尾巴欢快摇摆；
       - `mood: "curious"` -> 头部歪斜倾听角度加大，双耳高频微动；
       - `posture: "standing" | "crouching"` -> 根据语境自动在「乖巧坐姿」与「爬起站姿」之间切换；
       - 流式 Token 传输期间 -> 实时保持 `setTalking(true)`，让黑猫的“品”字形三格发光像素嘴随语调高频开合闪烁；流式结束瞬间自动 `setTalking(false)` 闭嘴。

【智能体四：全网深搜与权威引证智能体 (DeepSeek-V4-Pro Web Research Agent)】
--------------------------------------------------------------------------------
- 驱动模型: `deepseek-v4-pro`（`DeepSeek-V4-Pro-0813`）
- 专属工具:
  1. `POST https://api.deepseek.com/v1/tools/search`（DeepSeek 官方网页搜索）
  2. `POST https://api.deepseek.com/v1/tools/fetch`（DeepSeek 官方网页正文抓取）
  3. `deepseek-v4-pro` 模型内置 `web_search` 工具调用
- 触发方式:
  1. 用户点亮底部输入坞的 `[🌐 联网深搜 (Pro)]` 按钮；
  2. 用户提问中明确要求“帮我上网搜一下”、“给几个权威网站链接”、“查一下最新官方文档”。
- 执行流水线（AI 自主 Search -> Fetch -> 综合回答 + 权威外链卡片）:
  Step 1 [自主生成专业搜索词]:
    根据用户问题，提炼 1~2 个高精准度技术搜索词（例如针对官方文档、GitHub、MDN、Oracle、Spring、ArXiv 等专业站点）。
  Step 2 [调用 /v1/tools/search 搜索]:
    获取相关性最高的 Top 5 专业网页结果，并通过 SSE 向前端推送 `search_status` 事件（黑猫气泡实时显示：“🔍 已检索到 Oracle Docs、GitHub 等权威来源，正在深入阅读网页内容...”）。
  Step 3 [调用 /v1/tools/fetch 抓取正文]:
    挑选最权威的 2~3 个网页 URL 并发调用 `/v1/tools/fetch` 抓取干净正文（或在 `deepseek-v4-pro` 中通过内置 `web_search` 工具自动完成 Search+Fetch）。
  Step 4 [Pro 模型总结与权威外链引证]:
    `deepseek-v4-pro` 结合抓取到的权威内容进行深度解答，并在回答结尾通过 SSE 推送结构化外链数组 `citations`:
    ```json
    [
      {
        "index": 1,
        "title": "JEP 444: Virtual Threads - OpenJDK Official Documentation",
        "url": "https://openjdk.org/jeps/444",
        "domain": "openjdk.org",
        "snippet": "Virtual threads are lightweight threads that dramatically reduce the effort of writing, maintaining, and observing high-throughput concurrent applications."
      }
    ]
    ```
    前端在黑猫嘴巴放射的气泡底部渲染出带编号角标、域名徽章和外链箭头的「🌐 权威参考网站卡片」，用户点击即可在新标签页打开该专业网站！

     ```ts
     faceRig.getMouthWorldPosition(worldPos);
     worldPos.project(camera); // 投影至 [-1, 1] 标准设备坐标 (NDC)
     return {
       x: (worldPos.x * 0.5 + 0.5) * width,
       y: (-worldPos.y * 0.5 + 0.5) * height,
       visible: worldPos.z < 1.0
     };
     ```
